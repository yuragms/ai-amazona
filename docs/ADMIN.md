# Документация для администратора

Описание админ-панели и типичных задач. Доступ только для пользователей с ролью **ADMIN** (маршруты `/admin/*` защищены middleware и server actions).

## Вход в админку

- Перейдите по адресу `/admin` и войдите под учётной записью с ролью ADMIN (или используйте учётку из seed: `admin@example.com` / `admin123`).

## Разделы админ-панели

### Dashboard (`/admin`)

- **Метрики**: выручка, количество заказов, покупателей, средний чек.
- **Графики**: выручка по периодам, распределение заказов по статусам, пиковые часы заказов, новые и вернувшиеся клиенты, топ клиентов по выручке.
- **Недавние заказы**: таблица с сортировкой и фильтром по статусу, ссылки на детали заказа.
- **Низкий остаток**: товары с малым остатком и быстрая кнопка «Set» для обновления остатка.
- **Топ товаров**: по выручке.
- **Экспорт отчётов**: выбор периода, скачивание CSV и печать/PDF отчёта по заказам.

### Товары (`/admin/products`)

- Список всех товаров с категорией. Создание, редактирование и удаление товара.
- Загрузка изображений через Uploadthing (кнопка загрузки в форме товара).
- Массовое удаление: выбор строк и действие «Удалить выбранные».

### Заказы (`/admin/orders`)

- Список заказов с фильтрами по статусу и датам. Для каждого заказа — смена статуса (Pending → Paid → Processing → Shipped → Delivered и т.д.).
- Детали заказа: товары, адрес доставки, история статусов. При смене статуса на «Shipped» покупателю отправляется письмо об отправке (если настроен Resend).

### Пользователи (`/admin/users`)

- Таблица пользователей: имя, email, роль, количество заказов, дата регистрации.
- Смена роли (USER / ADMIN) через выпадающий список. Нельзя снять роль ADMIN с текущего вошедшего пользователя.

### Аналитика (`/admin/analytics`)

- Дополнительные отчёты и графики (пиковые часы, продажи по категориям и т.п.), при необходимости экспорт и печать.

## Уведомления

- В шапке админки — иконка уведомлений. Показываются оповещения о новых заказах и о товарах с низким остатком (данные обновляются по таймеру, например раз в 30 секунд).

## Отчёты и экспорт

- На Dashboard (и при необходимости на странице аналитики) доступен блок «Экспорт отчётов»: выбор дат, пресеты (7/30/90 дней), кнопки «Скачать CSV» и «Печать / PDF» для отчёта по заказам и выручке за период.

## Безопасность

- Все админские действия проверяют сессию и роль ADMIN на сервере. Не полагайтесь только на скрытие кнопок в интерфейсе — серверные проверки обязательны и уже реализованы в server actions.

## Переменные окружения для админ-функций

- **Uploadthing**: загрузка изображений товаров требует корректный `UPLOADTHING_TOKEN`.
- **Resend**: отправка писем (подтверждение заказа, «заказ отправлен») — `RESEND_API_KEY` и при необходимости `SENDER_EMAIL` / `SENDER_NAME`.

Подробнее о деплое и окружении см. [DEPLOYMENT.md](./DEPLOYMENT.md) и README.
